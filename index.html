02自傳

從學習與工作經驗中累積實作能力，持續精進程式開發與問題解決能力

我畢業於高雄科技大學機械工程系智能系統與控制組， 大學期間接觸程式設計與實作，並在「藍芽遠端遙控電風扇」專題中， 結合 3D 列印、Arduino、電路設計及簡易 App 開發，從實作與除錯過程中培養問題分析及團隊合作能力， 也因此對程式設計產生興趣。

畢業後參加產業新尖兵網站程式開發培訓，學習 PHP、Laravel 及 MySQL， 透過實際專案建立網站開發與資料庫操作基礎，並取得 TQC MySQL5 認證， 進一步確立投入軟體開發領域的方向。

進入職場後，主要擔任網站程式工程師，使用 ASP.NET MVC、C# 及 MS SQL Server 進行網站開發與系統維護，並參與 LINE Messaging API、藍新金流及 Google Apps Script 等服務整合。 同時使用 Windows 工作排程器執行 Python 程式，並參與房地產網站爬蟲開發， 累積 API 串接、資料處理、資料庫操作及自動化等實務經驗。

面對不熟悉的技術或開發問題，我習慣主動研究、測試與分析，找出適合的解決方式。 未來希望持續提升後端開發、API 整合、資料庫及自動化能力， 並進一步學習系統架構與雲端技術，持續累積實務經驗，為團隊與公司創造實際價值。
